# 🦖 Dino Runner
- Um jogo 2D inspirado em games clássicos, desenvolvido com HTML, CSS e JavaScript puro como projeto acadêmico para praticar lógica de programação e desenvolvimento web.

## 🎮 Demonstração

Acesse o jogo online:
https://gustvv-c.github.io/dino-run-js/

## 📖 Sobre o Projeto
- O Dino Run JS foi desenvolvido com o objetivo de aplicar conceitos fundamentais de programação, manipulação de elementos gráficos e organização de projetos web.
- Durante o desenvolvimento foram implementadas mecânicas como movimentação do personagem, sistema de colisão, pontuação e navegação entre telas.

## 🚀 Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## ✨ Funcionalidades
- Menu inicial
- Tela de instruções
- Tela de créditos
- Sistema de movimentação
- Mecânica de pulo
- Sistema de colisão
- Contagem de pontuação
- Reinício de partida
- Interface gráfica personalizada

## 🧠 Conceitos Aplicados
- Lógica de programação
- Manipulação do DOM
- Programação orientada a eventos
- Estruturação de projetos web
- Controle de fluxo
- Versionamento de código com Git
- Publicação de aplicações com GitHub Pages

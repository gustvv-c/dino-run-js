# 🦖 Dino Run JS

Jogo 2D desenvolvido em HTML, CSS e JavaScript como projeto acadêmico para aplicação de conceitos de lógica de programação, Canvas API e desenvolvimento web.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Sistema de colisão
- Física de pulo
- Pontuação
- Menu inicial
- Tela de instruções
- Créditos
